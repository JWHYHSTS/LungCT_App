# Bộ Font Chữ Y Tế: Be Vietnam Pro (LungCT Mobile)

## 1. Thông tin Nguồn gốc
- **Tên Font**: Be Vietnam Pro
- **Tác giả / Nhà thiết kế**: Lâm Bảo, Tony Le, ViệtAnh Nguyễn (The Be Vietnam Pro Project Authors).
- **Kho nguồn chính thức**: [https://github.com/bettergui/BeVietnamPro](https://github.com/bettergui/BeVietnamPro)
- **Kênh phân phối chính thống**: [Google Fonts - Be Vietnam Pro](https://fonts.google.com/specimen/Be+Vietnam+Pro)
- **Mục đích sử dụng**: Bộ font chữ chuẩn cho toàn bộ giao diện ứng dụng y tế `LungCT Mobile`, tối ưu hóa vượt trội cho dấu thanh tiếng Việt và hiển thị màn hình di động độ phân giải cao.

## 3. Danh mục Tệp Font Đóng gói trong Ứng dụng
1. `BeVietnamPro-Regular.ttf` (Regular, font-weight: 400) — Dùng cho các biến thể chữ nội dung: `bodyL`, `bodyM`, `bodyS`, `caption`.
2. `BeVietnamPro-Medium.ttf` (Medium, font-weight: 500) — Dùng cho các nhãn tương tác: `labelL`, `labelM`, `labelS`.
3. `BeVietnamPro-SemiBold.ttf` (SemiBold, font-weight: 600) — Dùng cho tiêu đề và số liệu: `display`, `titleL`, `titleM`, `titleS`, `numericM`.
